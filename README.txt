KIRUUU DREAMBOOK
================
A static, mobile-first personalized website built with HTML, CSS, and vanilla JavaScript.

FILES
- index.html: semantic page structure and all sections.
- style.css: Velvet Afterglow design tokens, responsive layout, components, and animations.
- script.js: the 100 apologies, grouped card rendering, progress, reveals, notes, photo lightbox, and final animation.
- assets/: the supplied image assets used by the website.

PREVIEW
Open index.html in a modern browser. The site does not require localhost, a build step, a server, or a continuously running phone. Google Fonts are optional; system fallback fonts are defined in CSS.

GITHUB PAGES
1. Create a GitHub repository named kiruuu-dreambook (or another name you prefer).
2. Upload index.html, style.css, script.js, README.txt, and the entire assets/ folder to the repository root.
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then save.
5. Wait for GitHub Pages to publish and open the public URL shown in Settings -> Pages.

All local assets use relative paths such as assets/dosa.jpg, so they work from a GitHub Pages project URL as well as a user-site URL. No preview URL, API key, database, login, or paid custom domain is required.

NOTES
- No backend, analytics, tracking, or real camera access is used.
- The camera-style ending is a visual animation only.
- The photo lightbox and interactions work without a framework.
- Check that you have permission to publish any images in the assets folder before making the repository public.
