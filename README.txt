KIRUUU DREAMBOOK
================
A static, mobile-first website built from your brief and the ten images uploaded in this chat.

LOCAL PREVIEW
- Extract this ZIP and open index.html in a modern browser.
- For a local server, run: python -m http.server 8000
  Then visit http://localhost:8000

PUBLISHING
Upload index.html and the assets/ folder together to a static host such as Netlify, Cloudflare Pages, or GitHub Pages. The website is not public until you publish it in a hosting account. Do not upload the images publicly unless you have permission to republish them.

NOTES
- Frontend-only: no database, login, analytics, or tracking.
- No music was supplied, so no track has been added.
- The existing Replit source was not included with the uploaded images, so this is a fresh replacement project, not a repair of the old deployment.
